Janitor-TTS-Tampermonkey

Auto Text-to-Speech for JanitorAI replies using ElevenLabs. This page is designed for GitHub Pages hosting.

Install Userscript GitHub Repo Releases

Quick Start

  1. Install Tampermonkey.
  2. Click Install Userscript above and confirm install/update.
  3. Open your JanitorAI chat page.
  4. In TTS panel: enter API key -> refresh voices -> select voice -> click Save.
  5. Chat and bot replies will auto-play if enabled.

Usage Flow (v1.7.0+)

  • Enter API key
  • Click refresh button beside Voice
  • Select voice
  • Optional: toggle Auto-play
  • Click Save (stored in localStorage)

GitHub Pages Setup

  1. Go to repo settings -> Pages.
  2. Set source to Deploy from a branch.
  3. Select branch main, folder / (root).
  4. Save and wait for publish URL.

Tip: keep userscript metadata @updateURL and @downloadURL pointed to the raw GitHub URL.
