JanitorAI + ElevenLabs TTS

A Tampermonkey userscript that adds Text-to-Speech via ElevenLabs to JanitorAI chat pages.

Installation

1 Install the Tampermonkey browser extension (Chrome, Firefox, Safari, Edge)
2 Click here to download the userscript — Tampermonkey will detect it and prompt you to install.
3 Visit your chat page — look for the TTS panel in the bottom-right corner.

Usage

1. Paste your ElevenLabs API key into the Key field
2. Select a voice from the Voice dropdown
3. Toggle Auto-play on/off as desired
4. Send a message — bot responses will auto-play!

Features

  • Auto-plays bot responses via ElevenLabs TTS
  • Voice selector (fetches available voices from your ElevenLabs account)
  • Auto-play toggle
  • Stop button to halt playback
  • Minimizable panel
  • Works on all JanitorAI chat pages

Serve this page locally on port 8015, or open the .user.js file directly in your browser.
